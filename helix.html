Overview

Helix is an enterprise-grade knowledge synthesis engine that combines dense and sparse retrieval methods with advanced document understanding. It enables organizations to unlock insights from unstructured data at scale, supporting everything from PDF parsing to real-time semantic search across millions of documents.

Built on a hybrid architecture that merges keyword-based BM25 retrieval with neural embedding models, Helix achieves high precision and recall across diverse document types. The system incorporates sophisticated chunking strategies, multi-stage reranking, and contextual expansion to deliver accurate results even for complex enterprise queries.

Capabilities

Hybrid Retrieval

Combines dense embeddings (BERT, Sentence-BERT) with sparse BM25 for optimal precision-recall balance.

Multi-Modal Ingestion

Supports PDF, DOCX, HTML, Markdown, and structured data with intelligent layout parsing and OCR.

Semantic Chunking

Context-aware document segmentation preserving semantic coherence across paragraph and section boundaries.

Advanced Reranking

Multi-stage reranking pipeline using cross-encoders and relevance feedback for top-k results.

Query Expansion

Automatic query reformulation and expansion using synonyms, entity recognition, and user intent modeling.

Scalable Indexing

Distributed vector search with FAISS and Elasticsearch integration, handling 12TB+ of indexed content.

Architecture

The Helix system is structured around three core layers: Ingestion (document parsing, OCR, metadata extraction), Indexing (chunking, embedding generation, vector and keyword index creation), and Retrieval (hybrid search, reranking, context synthesis). Each layer is horizontally scalable and fault-tolerant, leveraging Kubernetes for orchestration and Redis for caching.

Key directories include ingestor/ (multi-format parsers), embedder/ (BERT-based encoding pipelines), retriever/ (hybrid search logic), reranker/ (cross-encoder models), api/ (FastAPI endpoints), and workers/ (Celery-based async tasks for indexing and batch processing).
