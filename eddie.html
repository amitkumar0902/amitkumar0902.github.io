Overview

Eddie is the autonomous agent orchestration layer of the E42 AI platform. It enables enterprise customers to deploy AI agents that can reason, plan, use tools, and collaborate in multi-step workflows — all without human-in-the-loop supervision for routine tasks.

Built on a LangGraph-based hierarchical state machine, Eddie coordinates specialized agents (planner, executor, critic, memory) through directed acyclic task graphs. Each agent has its own tool registry, context window, and retry policy, enabling robust handling of long-horizon enterprise tasks like document processing, data reconciliation, and customer interaction workflows.

Eddie integrates deep with the Marvin inference layer for LLM calls and with Vortex for secure, multi-tenant deployment. Its guardrails module (a dedicated subdirectory) provides PII detection, content filtering, and compliance-aware output validation — critical for enterprise deployments.

Capabilities

Hierarchical Agent Graphs

LangGraph-powered DAG execution with supervisor agents orchestrating specialized subagents per domain or task type.

PII & Guardrails

Dedicated guardrails module with regex + ML-based PII detection, prompt injection defense, and output toxicity filters.

Persistent Memory

Stateful agent sessions backed by PostgreSQL + Redis. Agents can recall prior context across multi-session interactions.

MCP Gateway Integration

Native MetaMCP (mcps/) support — agents use standardized tool protocols for browser, filesystem, API, and DB interactions.

Workflow Automation

Pre-built PII workflow pipelines in workflows/pii/ with pytest test coverage. Configmap-driven deployment for rapid iteration.

Multi-tenant Deployment

Namespace-isolated via Vortex/GKE. Each customer tenant runs isolated agent instances with per-tenant rate limits and audit logs.

Tech Stack
Python LangGraph LangChain FastAPI Docker Kubernetes Redis PostgreSQL MetaMCP Qdrant GKE Keycloak pytest
Repository Structure

Key directories: agents/ (all agent definitions and tool registries), guardrails/ (PII, safety, compliance filters), mcps/ (MetaMCP protocol adapters), workflows/pii/ (end-to-end workflow definitions), deployment/ (K8s manifests and configmaps), supervisor_logs/ (structured runtime logging).
