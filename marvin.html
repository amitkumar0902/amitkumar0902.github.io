Overview

Marvin is the inference backbone of the E42 AI platform. It provides a unified layer for deploying large language models across heterogeneous hardware — from cloud A100/H100 clusters to on-premise GPU nodes. Designed for production-scale workloads, it supports multi-tenant request routing, dynamic batching, and model lifecycle management.

The system integrates llms_ground for model management and llamacpp for CPU/quantized inference, enabling flexible deployment without vendor lock-in. Speculative decoding and KV cache management are first-class primitives, yielding significant throughput improvements over vanilla vLLM or TGI setups.

Marvin also houses edith (embedding and reranking services), icr_ai (intelligent content routing), and account_ai (identity-aware request pipelines) — making it far more than a model server; it's a full AI compute runtime.

Capabilities

Speculative Decoding

Draft-model assisted token generation that increases effective throughput by 1.5–2.5x on standard LLM workloads.

Dynamic Quantization

INT4 / INT8 / FP16 kernel support via llamacpp and bitsandbytes. Configurable per-model per-namespace.

Multi-Tenant Isolation

Per-namespace model serving with Keycloak-based auth and API key management. Full audit logging via remote_logger.

Embedding & Reranking

Integrated edith module serves BGE / E5 family embedding models and cross-encoder rerankers for RAG pipelines.

KV Cache Management

NFS-backed persistent KV cache with configurable eviction policies. Dramatically reduces TTFT for long-context conversations.

CI/CD Integration

GitLab CI pipeline with automated Docker builds, staging promotion, and blue-green deployment via teamocil scripts.

Repository Structure

Marvin is a monorepo with microservice boundaries. Key modules: core_ai (request orchestration), account_ai (auth/identity), consumers (async task workers), edith (embeddings), icr_ai (content routing), deployment (K8s manifests & CI), prerequisites (infra bootstrap scripts).
