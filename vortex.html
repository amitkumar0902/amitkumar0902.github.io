Overview

Vortex is the infrastructure layer of the E42 AI platform. It abstracts all Kubernetes complexity behind a single shell CLI (v), letting engineers spin up fully isolated, production-ready AI environments on GKE with a single command sequence.

Each user or customer gets their own Kubernetes namespace with dedicated databases (Postgres, MongoDB, Redis, Qdrant, Neo4j), an LLM gateway (LiteLLM), an MCP gateway (MetaMCP), and optional services like RAGFlow, DocTR OCR, and Deskew. All services get auto-provisioned TLS, Keycloak-based auth, and ingress at user-service.e42.ai.

Vortex was designed to eliminate the 2-3 days of DevOps work previously required to onboard a new E42 customer. After Vortex, onboarding takes under 15 minutes.

CLI Commands
v create # namespace + infra + RBAC + TLS + NFS
v dbs create # Postgres, Mongo, Redis, Qdrant, Neo4j
v kubeai create # LLM / STT model inference (Helm)
v infinity create# Embedding + reranking models
v llm create # LiteLLM gateway with HPA
v mcp create # MetaMCP gateway (builds Docker image)
v rag create # RAGFlow + Infinity DB
v doctr create # DocTR OCR service
v get pods # kubectl passthrough
Capabilities

One-Command Deployment

Full AI stack (LLM gateway, databases, embeddings, RAG) provisioned via v create sequence. Idempotent and safe to re-run.

Multi-Tenant Isolation

Each user/customer is a Kubernetes namespace. Full RBAC, network policies, and secret isolation per tenant. URL pattern: user-service.e42.ai.

LiteLLM Gateway

Unified LLM API proxy with org/team/user management, API key lifecycle, and Horizontal Pod Autoscaling for burst traffic.

Zero-Trust Auth

Keycloak-powered identity with per-namespace secrets. API key creation, rotation, and deletion via v key CLI commands.

Guardrails Integration

LiteLLM guardrails layer for content filtering, prompt injection detection, and compliance-aware output validation.

NFS-Backed Storage

Source code and model weights served from NFS-backed PVCs. Shared storage enables fast model swapping without re-pulling images.
