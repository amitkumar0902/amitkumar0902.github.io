Full Mock Tests

Three families of NORCET Mains mocks: ten 160-Q balanced simulations (180 min each, +1 correct / −1/3 wrong) drawn from the full PYQ + high-yield bank; a PYQ-only mock of verified NORCET recalls; and per-paper verbatim replays — one mock per NORCET 1–9 Mains paper, plus sister staff-nurse exams (AIIMS pre-NORCET, JIPMER, RRB, ESIC, DSSSB) and YouTube-mined memory recalls. Each replay holds only that paper's questions — no blending. Results save locally with subject-wise analysis.

How to use them

  • Phase 1 (Days 1–5): Optional — attempt Mock 1 as a baseline only if time permits.
  • Phase 2 (Days 6–9): Mocks 2–4 at the end of each day.
  • Phase 3 (Days 10–13): Mocks 5–10, one per day; review wrong answers the same evening.
  • PYQ-only mock: warm-up built from every verified PYQ recall in the bank — good for Day 0 or a low-stakes confidence check.
  • NORCET 1–9 per-paper replays: attempt these to study how a single year's paper actually felt. NORCET 9 is verbatim from the official PDF; NORCET 1–8 are memory-based recalls.
  • Sister-exam replays (AIIMS / JIPMER / RRB / ESIC / DSSSB): useful to broaden exposure to the wider nursing-officer question style.
  • Always submit even if you don't finish. The dashboard needs the data to triage weak areas.
