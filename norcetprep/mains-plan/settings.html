Sync across devices

Move your progress (mock scores, streak, SRS, daily completion, settings) between phone and laptop without creating an account. Codes auto-expire after 15 minutes.

Send to another device

On your current device, generate a code. Then on the other device, open this page and paste the code below.

Receive from another device

Enter the 6-character code shown on your other device.

Manual export & import (no-internet fallback)

Save progress as a JSON file; then open the file on the other device. Works without sign-in.

Data

All progress is stored privately in this browser unless you explicitly share a sync code. Nothing else is sent to any server.

Install as app

On mobile: tap Share → Add to Home Screen. On desktop Chrome: click the install icon in the address bar. Works offline once cached.
